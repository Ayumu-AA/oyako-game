# 親子ゲーム

小学生の親子で遊ぶ、ブラウザ学習ゲーム集。スマホ・タブレット用。
プラウ経験型教育塾

## 中身

- **親子ヒントリレー**（2人）… 都道府県／世界の国旗／ことば／りか／えいご
- **はやおし親子バトル**（2人）… 画面を上下に分けて向かい合って対戦
- **親子クロスワード**（2人）… ヨコのカギ＝こども、タテのカギ＝おとな
- **ひとりであそぶ**（1人）… 10を作る／けいさんクロス

## 仕組み

`index.html` 1ファイルで完結。サーバー不要、初回読み込み後はオフラインでも動く。
記録は端末内（localStorage）にのみ保存される。

## 塾名などの書きかえ

`index.html` の `<script>` 冒頭にある `CONFIG` の3行だけを直す。

```js
const CONFIG = {
  schoolName: 'プラウ経験型教育塾',
  eventName : '',
  promoText : 'スコアを受付の先生に見せてね。参加賞をプレゼント！おうちでも遊べます。'
};
```

## 英語モードの絵の差し替え

同じく `<script>` 内の `IMAGES` に1行足すと、その単語だけ画像に置き換わる。

```js
IMAGES.apple = 'images/apple.png';
```
