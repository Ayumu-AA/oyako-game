親子ゲーム ／ ブース担当の方へ

1組あたり 5〜10分。この順番で回します

1
声をかける

「スマホで親子対戦できます。1回90秒です」

2
ポスターのQRを読んでもらう

おうちの方のスマホのカメラを向けるだけ。アプリのダウンロードは不要。
うまく読めないときは、こちらのスマホで読んで画面を見せる。

3
がくねんとゲームを選ぶ

低学年 → 親子ヒントリレー（都道府県・国旗）／高学年 → はやおし親子バトル
迷ったら「ミックス」でOK。待ちが出ているときは短い「はやおしバトル 5もん先取」。

4
遊ぶ（90秒）

はやおしバトルは スマホを机に置いて向かい合う。こどもが画面の上の側にすわる。
声が出るほど、次の親子が寄ってきます。盛り上げてOK。

5
結果画面を見せてもらう → 参加賞をわたす

「よくできました。これ、おうちでも同じQRで遊べます」

6
持ち帰りカードをわたす

参加賞といっしょに1枚。カードのQRからも同じゲームが開きます。

掲示用ランキング（別の画面）

ノートPCかタブレットで https://ayumu-aa.github.io/oyako-game/board.html?e=T2026-12 を開いて、 ブースに向けて置いておきます。新しい点数が入ると、その瞬間に名前が出ます。

スリープ設定を切っておくこと。電源につないだままにする。

気をつけること

1台のスマホを何組にも貸すときは、名前を入れないでください。
同じ端末は「同じ人」として記録されるため、あとの組が名前を入れると、前の組の点数の名前まで 変わってしまいます。貸出用の端末では 「ランキングを見る」を押さないで、その場の勝ち負けだけ楽しむ形に。

本名は入れない。名前の画面に「ほんとうの なまえは いれないでね」と出ます。 ひらがな2〜6文字のニックネームです。サイコロのボタンで候補も出ます。

運営者用

その場で直せること

こうなったらこうする
画面が白いまま／古い画面が出る ページを2回リロード。新しい版は1回目の裏で読みこまれ、2回目で切りかわります。
ランキングが出ない 8秒で「つながると出ます」に変わります。ゲームは止まりません。点数は端末にたまっていて、つながった時に自動で送られます。そのまま進めてOK。
電波が届かない 一度開いた端末は、そのまま遊べます（機内モードでも動く作り）。記録はあとから上がります。
掲示の画面が止まった ブラウザのリロード。それでもだめなら一度閉じて開き直す。
名前をまちがえた／変えたい タイトル画面の右上「せってい」→ なまえ を変える。過去の点数の名前も全部そろいます。

変な名前が掲示に出たとき

Supabase の画面 → SQL Editor を開いて、次の1行を貼って Run。すぐ消えます。

update public.profiles set nickname = 'ななしさん' where nickname = 'ここに その名前';

同じような言葉を今後ぜんぶ禁止にするなら、2行貼って Run：

insert into public.ng_words(word) values ('ことば') on conflict do nothing;
select public.ng_apply();

アプリの入れ直しは要りません。次から入力の時点ではじかれ、すでに入っている名前も置きかわります。

前日に かならず やること

  • Supabase を起こす。7日間さわらないと寝てしまいます。画面を開いて、寝ていたら「Restore」。 そのあと実際に1プレイして、掲示に出るところまで確認。
  • Pro プランに切りかえる（当日の人数に備えて。終わったら戻す）。
  • ポスターを印刷して貼る。持ち帰りカードを人数分＋予備。
  • 自分のスマホでポスターのQRを実際に読んで、開くところまで試す。
  • 掲示用のPC／タブレットを充電し、スリープを切って、board の画面を開いておく。
  • テスト用に入れた点数を消す：delete from public.scores where event_code = 'TEST';
